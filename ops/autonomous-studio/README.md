# God Molecule Autonomous Character Stack

This is the autonomous character/animation/render/evidence team. It shares the same control-plane contract as TRIPPEDD while keeping God Molecule's Blender and physical-evidence tools authoritative.

Agents may repair rigs, run Blender, render evidence, measure geometry and recover failed jobs. They may not replace canonical assets, invent measurements, or claim PASS without physical evidence.

Private-repository credentials are runtime secrets only and are never committed.
