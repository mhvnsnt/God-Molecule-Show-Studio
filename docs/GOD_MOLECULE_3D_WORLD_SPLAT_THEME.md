# God Molecule — 3D World / Gaussian Splat Background Theme

## Status

This is a **show-level background production theme and studio capability layer**. It expands the God Molecule visual language without replacing the existing Show Bible, Mars identity, story, character personalities, or canonical assets.

The rule is: **the world may transform radically; Mars does not lose identity.**

## Core visual idea

God Molecule can treat reality as a navigable 3D/radiance-field substrate:

`physical scene → scanned/reconstructed space → Gaussian splat/radiance layer → procedural molecular layer → animated scene → cinematic render`

A scene can move between ordinary physical space and impossible consciousness-space without a hard production boundary.

Gaussian splats are especially useful as a **background/world medium**: photographic environments, dream spaces, neighborhoods, rooms, cosmic voids, microscopic worlds, and transitional memory fragments can become navigable radiance fields while conventional Blender geometry remains available for characters, props, collisions, hero objects, and effects.

## God Molecule physics language

The molecular layer is a **visual and storytelling system**, not a claim about real physics.

The studio can simulate:

- Verlet-style particle motion
- harmonic springs / covalent bond oscillation
- thermal Brownian noise
- electrostatic-style forces
- God-Field resonance perturbations

These can drive visible motion, light, camera behavior, splat displacement, particles, transitions, or environmental reactions.

## Preset world families

The background system should support reusable world recipes such as:

1. God Molecule / Fullerene C60
2. DNA quantum double helix
3. superconducting torus lattice
4. cyberpunk splat alley
5. cosmic nebula splat void

These are starting environments, not limits. Episode-specific worlds can be generated from the existing show cosmology.

## Cinematic AI director layer

The AI director is an orchestration layer. It proposes and executes **real scene operations** through the production runtime; it does not become a second source of truth.

Useful capabilities include:

- high-thinking scene planning and molecular/world formulas
- fast conversational parameter changes
- director chat with role/persona presets
- image/reference analysis
- skybox and panoramic texture generation
- image editing
- cinematic video generation from approved snapshots/prompts
- atmospheric music generation
- character/world voiceover
- microphone transcription into director commands
- reference-photo/video landmark analysis
- search/maps grounding when an episode intentionally uses real-world context

Provider-specific model names and preview APIs are implementation adapters, not show canon. They may change without changing the creative architecture.

## Character + world composition

Mars remains a conventional, production-grade hero character:

- canonical mesh and facial authority
- real rig / weights
- facial expressions
- real animation
- real materials
- real render/pixel evidence

The world can be hybrid:

**Gaussian splat environment + conventional Blender geometry + particles/procedural molecular structures + physically rigged Mars.**

This is the important production split. Splat data can carry the environment's visual richness without forcing every background surface into the same topology/deformation problem as Mars.

## Animation model

A scene is a set of independently addressable tracks:

- character transforms
- facial controls
- object transforms
- camera
- splat/world parameters
- molecular simulation parameters
- lighting
- effects
- audio
- transitions

The timeline should support 24/30/60 fps and normal keyframe/sequencer workflows. Generated animation is accepted only after the resulting artifact is rendered and inspected.

## Evidence and provenance

Every important world/character artifact should carry:

- canonical asset identity
- source artifact
- scene/world ID
- camera/view
- frame or frame range
- dimensions
- source job/run
- timestamp
- SHA-256
- provenance
- QC status
- operation ID / receipt where produced by the live runtime

The governing production rule remains:

**Numerical PASS + visual FAIL = FAIL.**

AI-generated media, splat captures, generated skyboxes, and cinematic previews are candidates until their actual pixels and provenance are verified.

## Integration with the existing show

This layer sits underneath the existing God Molecule story:

- surreal anthology structure
- Mars as the anchor consciousness
- reality transitions as storytelling
- philosophy and comedy together
- internal logic beneath apparent randomness
- mutable style with immutable character identity
- consciousness as cosmological substrate

The new world system therefore becomes a **visual grammar for how Mars's consciousness can render reality**, not a replacement for the story bible.
