## 5. Episode construction `[W2]`

Every episode runs the same machine (all three inspirations agree):

1. **Ritual open:** Void → look left → look right → "Oh, hey." Lock the sequence; vary exactly one element per episode.
2. **Thesis plant:** Mars delivers one Ice-Cream Koan that secretly names the episode's theme.
3. **Arrival:** through the forehead portal into a new reality, filed under one of the four lands (Life / Time / Desire / Dreaming) + Central Mountain.
4. **Premise:** one central question from the KEEP-verdicted list, posed in-world, never answered cleanly.
5. **Escalation:** Mars applies deadpan wrong philosophy; Kevin runs parallel chaos; the world's rules punish wrong assumptions.
6. **Anti-ending:** reset, death-as-transition, or the shrug. No clean lessons.

## 6. Reality taxonomy

### 6.1 The anthology schema `[B-KEEP]`

Every episode can enter a completely different reality. Owner-verdicted list,
expanding toward **almost infinite worlds**:

cheap old video game · psychedelic children's program · abandoned mall · cosmic horror landscape · suburban backyard · microscopic world · fake documentary · dream · medical simulation · 3D game · crude 2D animation · found footage · live-action/AI-assisted footage · completely abstract universe · …

### 6.2 The four-land elemental taxonomy `[W2]`

Realities file under four lands + Central Mountain (Tong-Nou). Each land locks three axes — **element, music, soul-force**:

- **Life** = Wood · organic/techno-house textures · growth-duty
- **Time** = Fire · driving percussion · urgency-duty
- **Desire** = Metal · sharp synthetic textures · appetite-duty
- **Dreaming** = Water · fluid ambient textures · memory-duty
- **Central Mountain** = the trickster hub (Kevin's territory): barter-only, published-but-absurd exchange rates, no money, every trade has a catch.

A reality isn't just themed; it has a locked elemental signature + musical palette. This is how "almost infinite" stays navigable.

### 6.3 Cosmology scale stack `[B-KEEP]` + `[W2]`

thoughts → memories → simulated realities → dimensions → universes → multiverses → galaxies → microscopic worlds → quantum-scale phenomena → abstract mathematical spaces

Plus the open question: **Is Mars containing everything, or is something containing Mars?** `[B-KEEP]`

*Expansion note `[W2]`: the scale stack is not a ladder the show climbs — episodes can enter at any rung, and the four-land taxonomy (§6.2) is the filing system that keeps infinite instances navigable.*
