# Video Fix Tools — Open Source Animation Pipeline

Tools for fixing AI-generated video back to 2D cartoon style.

## Tools to pull in:
1. EbSynth - style transfer via keyframe painting
2. OpenRotoscope - DaVinci Resolve rotoscoping
3. Natron - compositing
4. Synfig Studio - 2D animation
5. OpenToonz - 2D animation (Ghibli's tool)
6. Krita - 2D painting/animation
7. Blender VSE - video editing
8. FFmpeg - video processing
9. OpenCV - computer vision
10. RIFE - frame interpolation
11. Real-ESRGAN - upscaling
12. Stable Diffusion + ControlNet - stylization
13. TupiTube - 2D animation
14. Pencil2D - 2D hand-drawn animation
15. Enve - 2D animation
